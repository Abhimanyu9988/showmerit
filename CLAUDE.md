# ShowMerit rules

- Every number on a page must match the items shown, and every claim needs a proof link.
- No invented users, counts, logos or testimonials. No scores, rankings or visa language.
- The owner's tracker stays off public pages.
- Name only sources that really import.
- The try-it box runs in the visitor's browser and saves nothing.
- Run `python build.py && python tools/check.py` before pushing.
- Never commit credentials. Sign-up and passwords can't run on GitHub Pages.
